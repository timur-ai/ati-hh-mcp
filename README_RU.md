# ati-hh-mcp

Публичный MCP-сервер (Model Context Protocol) для API hh.ru: все операции
публичной OpenAPI в переключаемых наборах инструментов, два транспорта
(stdio и HTTP) и гибридная авторизация hh.ru (токен или OAuth).

**Статус: WIP** – ранняя разработка (этап M1: вертикальный срез).
Инструкция быстрого старта, справочник конфигурации и каталог инструментов
появятся в финальном этапе документации.
