# ati-hh-mcp

Public MCP (Model Context Protocol) server for the hh.ru API: every public
OpenAPI operation exposed as grouped, switchable toolsets, with stdio and
HTTP transports and hybrid hh.ru authorization (token or OAuth).

**Status: WIP** – early development (milestone M1: vertical slice). Quick
start, configuration reference and the full tool catalog will land in the
final documentation milestone.
